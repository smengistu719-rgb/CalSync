Excel VBA & Formula Code Generator

Copy these custom VBA functions directly into your Excel workbook (`ALT + F11 > Insert > Module`) to compute Ethiopian dates directly inside cell formulas like `=EthiopianToGregorian(A2)`.

VBA Function: Ethiopian to Gregorian 

Function EthiopianToGregorian(eDay As Integer, eMonth As Integer, eYear As Integer) As Variant
    ' Valid for Excel's date range (Gregorian 1901-2099)
    Dim startOfEthYear As Date
    Dim maxDay As Integer

    If eMonth < 1 Or eMonth > 13 Or eDay < 1 Then
        EthiopianToGregorian = CVErr(xlErrValue): Exit Function
    End If
    If eMonth = 13 Then
        If eYear Mod 4 = 3 Then maxDay = 6 Else maxDay = 5
    Else
        maxDay = 30
    End If
    If eDay > maxDay Then
        EthiopianToGregorian = CVErr(xlErrValue): Exit Function
    End If

    ' New Year is 12 Sep when the previous Ethiopian year was a leap year, else 11 Sep
    If eYear Mod 4 = 0 Then
        startOfEthYear = DateSerial(eYear + 7, 9, 12)
    Else
        startOfEthYear = DateSerial(eYear + 7, 9, 11)
    End If

    EthiopianToGregorian = startOfEthYear + (eMonth - 1) * 30 + (eDay - 1)
End Function

VBA Function: Gregorian to Ethiopian 

Function GregorianToEthiopian(gDate As Date) As String
    ' Valid for Excel's date range (Gregorian 1901-2099)
    Dim gYear As Long, dayOfYear As Long
    Dim eYear As Long, eMonth As Long, eDay As Long
    Dim startOfEthYear As Date

    gYear = Year(gDate)
    eYear = gYear - 7
    If eYear Mod 4 = 0 Then
        startOfEthYear = DateSerial(gYear, 9, 12)
    Else
        startOfEthYear = DateSerial(gYear, 9, 11)
    End If

    If gDate < startOfEthYear Then
        eYear = gYear - 8
        If eYear Mod 4 = 0 Then
            startOfEthYear = DateSerial(gYear - 1, 9, 12)
        Else
            startOfEthYear = DateSerial(gYear - 1, 9, 11)
        End If
    End If
    dayOfYear = CLng(gDate - startOfEthYear) + 1

    If dayOfYear <= 360 Then
        eMonth = Int((dayOfYear - 1) / 30) + 1
        eDay = ((dayOfYear - 1) Mod 30) + 1
    Else
        eMonth = 13
        eDay = dayOfYear - 360
    End If

    GregorianToEthiopian = Format(eDay, "00") & "/" & Format(eMonth, "00") & "/" & eYear
End Function

4-Year Evangelist Cycle

Ethiopian years follow a 4-year cycle named after the four Evangelists:

  • • John (ዮሐንስ) - Leap Year (Pagume has 6 days)
  • • Matthew (ማቴዎስ) - Standard Year
  • • Mark (ማርቆስ) - Standard Year
  • • Luke (ሉቃስ) - Standard Year
